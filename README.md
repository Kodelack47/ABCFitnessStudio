ABC fitness studio website built with HTML, CSS, and JavaScript.

Live Site:** [View Project]-https://kodelack47.github.io/abc-fitness-studio/gallery.html

## Pages

- **Home** - Welcome page with studio information
- **Gallery** - Product gallery with Add to Cart functionality
- **About Us** - Studio information and contact form
- **Community** - Community corner page

## Features

- Responsive design
- Simple JavaScript alerts for user interactions
- Contact form with validation
- Subscribe button in footer

## How to Use

1. Clone this repository
2. Open `index.html` in your browser
3. Navigate through the pages using the menu

## Files

- `index.html` - Homepage
- `gallery.html` - Gallery page
- `aboutus.html` - About Us and contact page
- `community.html` - Community page
- `style.css` - Stylesheet for all pages

## Technologies Used

- HTML5
- CSS3
- JavaScript
